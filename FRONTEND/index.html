How It Works

From secure access to actionable intelligence.

  1. 01

    Officer logs in : Opens the Chakravyuha dashboard.

    System responds : Securely loads the workspace and shows available case options.

  2. 02

    Officer uploads/selects data : Case files, phone records, financial transactions, or surveillance logs.

    System processes : Cleans the data instantly and prepares it for analysis.

  3. 03

    Officer chooses analysis type : For example: “Find suspect connections.”

    System builds graph : Converts people, places, and events into nodes and links.

  4. 04

    Officer views dashboard : Sees the network map on screen.

    System highlights : Shows clusters, hidden links, and suspicious activity patterns.

  5. 05

    Officer clicks on a suspect : Wants to know who they are connected to.

    System reveals : Displays all direct and indirect connections, plus frequency of interactions.

  6. 06

    Officer reviews insights : Checks who is most influential or risky in the network.

    System suggests : Prioritizes suspects, predicts possible next moves, and flags high-risk links.

  7. 07

    Officer decides action : Investigate further, alert the team, or plan an operation.

    System ensures : All data remains secure, logged, and accessible only to authorized officers.
